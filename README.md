# Low-Cost Mini 3-Axis CNC Plotter

Designed and fabricated a functional, low-cost 3-Axis Mini CNC Plotter capable of executing precise drawing, writing, and vector graphics plotting using a pencil/pen tool head.

## 🚀 Project Overview
This project builds an affordable CNC machine by repurposing optical drive components and pairing them with standard open-source micro-controller firmware for accurate two-axis linear positioning and tool lifting.

## 🛠️ Key Features
- **Microcontroller & Firmware:** Utilized an Arduino Nano flashed with GRBL firmware to interpret G-code signals into real-time step and direction commands.
- **Motor Control System:** Integrated an Arduino CNC Shield (v3) fitted with A4988 motor drivers to deliver smooth microstepping control.
- **Recycled Mechanics:** Extracted and modified compact mini-stepper motors with lead-screw assemblies from recycled DVD optical drives for precise X and Y axes motion.
